# NexTune — Plano 4: Disco e Atualizações

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar o módulo Disco (estado das unidades fixas, verificação online só de leitura, correção agendada para o próximo reinício com a lição do Positivo sobre Inicialização Rápida, e otimizar = desfragmentar em HDD ou TRIM em SSD, nunca o contrário e só com volume limpo) e o módulo Atualizações (Windows Update via COM sem Upgrades nem Preview por padrão, programas via `winget upgrade` com parser independente de idioma, instalação das selecionadas).

**Architecture:** Mesma ponte dos Planos 1 a 3 (UI → comandos Tauri → `host.ps1` → `scripts/<modulo>.ps1`). Dois módulos PowerShell novos (`disco.ps1`, `atualizacoes.ps1`), nenhuma lista de dados nova, allowlist e validação estendidas em `acoes.rs`, duas vistas novas e um cartão novo no Início. `Get-TipoDisco` e a leitura de `HiberbootEnabled` sobem de `diagnostico.ps1` para `common.ps1` porque `disco.ps1` também usa. A última verificação de cada unidade fica em `Estado\disco.json` (registro do próprio programa, complementado pelos eventos de chkdsk do Windows).

**Tech Stack:** o mesmo dos Planos 1 a 3. Nada novo além de `Repair-Volume -Scan`, `Optimize-Volume -Defrag|-ReTrim`, `fsutil dirty set`, `Win32_Volume.DirtyBitSet`, `shutdown.exe`, COM `Microsoft.Update.Session` e `winget.exe`.

**Spec:** `docs/superpowers/specs/2026-11-20-otimizador-design.md` §7 (regras de disco), §8.6, §8.7 (menos o atualizador do próprio NexTune, que é do Plano 5), §9.5, §9.7, §11 (cartão "Disco sem verificação"), §13 ("TRIM em HDD deve ser recusado", "parser do winget com saídas gravadas").

**Plano anterior:** `2026-11-20-inicializacao-ajustes-windows.md` (concluído). **Planos seguintes:** 5 Modo Jogo + bandeja + lembretes + atualizador; 6 site, README e primeira release.

## Global Constraints

Valem todas as dos Planos 1 a 3 (PowerShell 5.1, BOM nos `.ps1`, sem `Invoke-Expression`, argumentos em lista, textos só em `ui/i18n/pt-BR.js`, `esc()`/nós DOM, commits pequenos em português; ambiente sem Rust nem Pester 5: scripts carregados localmente, funções puras exercitadas à mão, Rust e Pester confirmados no Actions após o push). Mais estas:

- **Regras de disco (spec §7) valem pelo disco físico da unidade, não pelo perfil:** `otimizar` decide `desfragmentar` × `trim` pelo `MediaType` do disco físico daquela letra (`hdd` → desfragmentar; `ssd`/NVMe → TRIM). Ilegível conta como `hdd`. TRIM em HDD e desfragmentação em SSD nunca acontecem, nem no modo avançado.
- **Só volume limpo é otimizado:** `otimizar` exige, para aquela letra, bit sujo desligado **e** uma `verificar` registrada em `Estado\disco.json` com `semErros:true`. Sem isso devolve `ok:false` com o motivo, e a interface já mostra o botão travado com a dica "verifique antes".
- **Verificar nunca escreve no volume:** `verificar` é `Repair-Volume -Scan` (online, só leitura). `corrigir` não corrige na hora: marca o volume para o `autochk` do próximo reinício (`fsutil dirty set X:`, o mesmo efeito de `chkdsk /f` agendado, sem desmontar unidade de dados em uso). O programa **não** desliga a Inicialização Rápida: devolve `inicioRapido` e a interface orienta "Reiniciar, não Desligar" e oferece `reiniciar` (`shutdown /r`, que não hiberna). A alternativa pelo Ambiente de Recuperação (`reagentc /boottore`) é só texto na tela.
- **Unidades: só fixas e prontas** (`DriveType = Fixed`, `IsReady`), as mesmas do Diagnóstico. Letra fora dessa lista é recusada em toda ação (`unidade não encontrada`). O Rust só confere a forma `^[A-Z]:$`.
- **Windows Update:** critério `IsInstalled=0 and IsHidden=0 and Type='Software'` (drivers ficam fora: verificação de drivers é fora da v1). Upgrades (categoria `3689BDC8-B205-4AF4-8D4A-A63924C5E9D5` ou nome `Upgrades`) **nunca** são instalados, nem no avançado; só aparecem no avançado, travados, com o motivo. Preview (`Preview|Prévia|Visualização` no título) só aparece e só instala com `avancado:true`.
- **winget:** sempre `--accept-source-agreements --disable-interactivity`; na atualização também `--id <id> --exact --silent --accept-package-agreements`. O id vai como argumento de lista (nunca em string de comando) e já chegou validado pelo Rust (`^[A-Za-z0-9][A-Za-z0-9._+-]{0,127}$`). winget ausente ou WU com erro COM não derrubam `listar`: a outra metade vem e o erro fica no campo (`winget.erro`, `windowsErro`).
- **Toda escrita em `Write-AppLog`:** corrigir, reiniciar, otimizar, instalar, atualizarProgramas. `verificar` também loga (resultado), por ser lento e útil no suporte.
- **Sem rede a partir da interface (spec §9.6):** quem fala com a Microsoft é o Windows Update e o winget, no host elevado. A interface só mostra o que o script devolveu.

## Review Focus

Entradas que a spec implica e que um teste fixa (cada uma com teste nomeado na tarefa dona):

1. **TRIM em HDD recusado e desfragmentação em SSD recusada** (spec §13): com unidade simulada `hdd`, `otimizar` grava a operação `desfragmentar`; com `ssd`, `trim`; nunca o inverso. E sem `verificar` sem erros registrada, ou com bit sujo, `otimizar` devolve `ok:false` e não grava operação. → Tarefa 2.
2. **Letra fora da lista** (`Z:` inexistente, pendrive, unidade de rede): `verificar`, `corrigir` e `otimizar` devolvem `ok:false` "unidade não encontrada" e nada é gravado. → Tarefa 2 (Rust recusa a forma `c:`, `C`, `C:\`). → Tarefa 1.
3. **Corrigir com Inicialização Rápida ligada:** o resultado traz `inicioRapido:true` e `agendada:true`; `estado` em seguida mostra `agendada:true` para aquela letra (bit sujo lido do simulado). A interface mostra "Reiniciar, não Desligar" e o botão Reiniciar agora. → Tarefas 2 e 4.
4. **`instalar` nunca instala Upgrade, mesmo com `avancado:true`; Preview só com `avancado:true`:** os ids recusados vão para `falhas` com o motivo; os demais da mesma chamada seguem. → Tarefa 3.
5. **Parser do winget** com saída pt-BR e en-US gravadas, nome truncado com `…`, spinner e `\b` no começo, rodapé "N atualizações disponíveis" e segunda tabela ("fixadas") depois: as duas saídas dão a mesma lista de ids; saída vazia ou "Nenhuma atualização" dá lista vazia, nunca erro. → Tarefa 3.
6. **winget ausente ou WU com erro COM:** `listar` devolve `ok:true` com a metade que deu, `winget.disponivel:false` ou `windowsErro` preenchido. → Tarefa 3.
7. **`disco.json` corrompido ou ausente:** `estado` funciona com `ultimaVerificacao:null` para todas as letras (nunca verificado por aqui), e a próxima `verificar` regrava o arquivo inteiro. → Tarefa 2.

## Contratos (JSON, camelCase; o PowerShell devolve exatamente estes nomes)

### disco
- `estado {}` → `{ unidades: [{ letra: 'C:', rotulo, total, livre, tipoDisco: 'hdd'|'ssd', sistema, sujo, agendada, ultimaVerificacao (ISO|null), semErros (bool|null), diasSemVerificar (int|null) }], inicioRapido }`.
  - `tipoDisco`: `Get-Partition -DriveLetter → Get-Disk → Get-PhysicalDisk`, `Get-TipoDisco MediaType BusType` → `HDD` vira `hdd`, `SSD`/`NVMe` viram `ssd`; qualquer erro vira `hdd`. `sujo` = `(Get-CimInstance Win32_Volume -Filter "DriveLetter='C:'").DirtyBitSet` (independente de idioma; `fsutil dirty query` não é). `agendada` = `sujo` **ou** `Test-UnidadeAgendada $bootExecute 'C:'` (algum item de `HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\BootExecute` casa `autochk.*\\\?\?\\C:` sem diferenciar caixa).
  - `ultimaVerificacao` = a mais recente entre o registro próprio (`Estado\disco.json`: `{ "C:": { "verificadoEm": ISO, "semErros": bool } }`) e os eventos do Windows (`Get-WinEvent -FilterHashtable @{LogName='Application'; ProviderName='Microsoft-Windows-Wininit'; Id=1001}` → unidade do sistema; `ProviderName='Chkdsk'; Id=26226,26212,26214` → letra `([A-Z]):` na mensagem, senão unidade do sistema; `-MaxEvents 20` cada). `semErros` só vem do registro próprio (evento não diz). `diasSemVerificar` = `Get-DiasDesde $iso (Get-Date)` (inteiro, arredondado para baixo) ou `null`.
  - Modo teste: `simular { unidades: [{ letra, rotulo, total, livre, tipoDisco, sistema, sujo, agendada }], inicioRapido? }` substitui toda leitura real (sem `Get-Partition`, sem eventos, sem `Win32_Volume`); registro próprio em `%TEMP%\NexTuneTeste\Estado\disco.json`. Sem `simular` em teste, `unidades` vem vazia.
- `verificar { letra }` → `{ letra, resultado, semErros, verificadoEm }`. `resultado` = texto do enum de `Repair-Volume -DriveLetter C -Scan` (`NoErrorsFound`, `ErrorsFound`, `ErrorsFixed`, `ScanNeeded`, ...); `semErros` = `resultado -in 'NoErrorsFound','ErrorsFixed'`. Grava `Estado\disco.json` (sobrescreve a entrada daquela letra; é registro, não backup). Progresso: 10 "Verificando C: (pode levar alguns minutos)", 100. Teste: `simular.resultado` (padrão `NoErrorsFound`) e marcador `%TEMP%\NexTuneTeste\disco\verificar-C.txt`.
- `corrigir { letra, confirmado: true }` → `{ letra, agendada: true, inicioRapido }`. Real: `& "$env:windir\System32\fsutil.exe" dirty set "C:"`; `$LASTEXITCODE -ne 0` lança. Teste: marcador `corrigir-C.txt` e, para `estado` refletir, o simulado daquela letra passa a `sujo:true` **só se** o teste reenviar `simular` assim (o script não guarda estado simulado; o teste é quem simula o bit).
- `reiniciar { confirmado: true }` → `{ agendado: true }`. Real: `& "$env:windir\System32\shutdown.exe" /r /t 10 /c "NexTune: reiniciando para verificar o disco"`. Teste: marcador `reiniciar.txt`.
- `otimizar { letra, confirmado: true }` → `{ letra, operacao: 'desfragmentar'|'trim' }`. Antes: `Test-PodeOtimizar $unidade` → `@{ pode; motivo }` (`sujo` → "o volume está marcado para verificação; reinicie antes"; sem registro ou `semErros:false` → "verifique a unidade antes de otimizar"). `Get-OperacaoOtimizar $tipoDisco` → `hdd` = `desfragmentar` (`Optimize-Volume -DriveLetter C -Defrag`), senão `trim` (`-ReTrim`). Progresso: 10 "Otimizando C: (em HDD pode levar horas)", 100. Teste: marcador `otimizar-C.txt` com a operação.
- Toda ação com `letra`: `Get-UnidadePorLetra $letra $unidades` (lista de `Get-Unidades`); `$null` → `ok:false` "unidade não encontrada: X:".

### atualizacoes
- `listar { avancado? }` → `{ windows: [{ id, titulo, kb (string|null), tamanhoBytes, categorias: [string], tipo: 'seguranca'|'critica'|'definicao'|'qualidade'|'outro', exigeReinicio, excluido: null|'upgrade'|'preview' }], windowsErro (string|null), programas: [{ id, nome, versaoAtual, versaoNova, origem }], winget: { disponivel, erro (string|null) } }`.
  - WU: `(New-Object -ComObject Microsoft.Update.Session).CreateUpdateSearcher().Search(<critério>)`; por `Updates[i]`: `id` = `Identity.UpdateID`, `kb` = `KBArticleIDs[0]` com prefixo `KB` (ou `null`), `tamanhoBytes` = `MaxDownloadSize`, `categorias` = nomes, `exigeReinicio` = `InstallationBehavior.RebootBehavior -ne 0`, `tipo` = `Get-TipoAtualizacao $categorias` (lista de `@{ id; nome }`: `0FA1201D-4330-4FA8-8AE9-B877473B6441` → `seguranca`, `E6CF1350-C01B-414D-A61F-263D14D133B4` → `critica`, `E0789628-CE08-4437-BE74-2495B842F43B` → `definicao`, `CD5FFD1E-E932-4E3A-BF74-18BF0B1BBD83` → `qualidade`, senão `outro`), `excluido` = `Test-Excluida $titulo $categorias` (`upgrade` pelo id/nome da categoria; `preview` pelo título). Sem `avancado:true`, itens `excluido` não vão na lista. Erro COM → `windows: []`, `windowsErro` = mensagem.
  - winget: `Get-ComandoWinget` → `(Get-Command winget.exe -ErrorAction SilentlyContinue).Source` ou `Join-Path $env:LOCALAPPDATA 'Microsoft\WindowsApps\winget.exe'` se existir; senão `winget.disponivel:false`, `erro` "winget não encontrado". Saída de `& $winget upgrade --include-unknown --accept-source-agreements --disable-interactivity` (stdout como `string[]`, `2>&1` descartado) passa por `ConvertFrom-TabelaWinget`.
  - `ConvertFrom-TabelaWinget([string[]]$Linhas)` → lista de `@{ id; nome; versaoAtual; versaoNova; origem }`. Puro: remove `\b` e `\r` e espaços à direita; acha a **primeira** linha `^-{10,}\s*$`; o cabeçalho é a linha anterior; colunas começam onde o cabeçalho tem palavra precedida de ≥ 2 espaços (ou coluna 0); ordem fixa Nome, Id, Versão, Disponível, Origem (os títulos variam por idioma, as posições não). Linhas de dados: da seguinte ao separador até a primeira linha vazia ou que não alcança o início da coluna Id; cada campo é o recorte entre os inícios, `Trim()`. Linha sem id (vazio) é ignorada. A segunda tabela (fixadas/desconhecidas) e o rodapé "N atualizações disponíveis" ficam fora.
  - Modo teste: `simular { windows: [...] (vai inteiro na saída, só filtrado por excluido/avancado), windowsErro?, wingetLinhas: [string], wingetAusente: bool }`; nunca COM nem winget.
- `instalar { ids, confirmado: true, avancado? }` → `{ instalados: [id], falhas: [{ id, erro }], precisaReiniciar }`. Real: nova busca com o mesmo critério; para cada id: ausente → falha "atualização não está mais disponível"; `upgrade` → falha "atualização de versão do Windows fica fora: use as Configurações"; `preview` sem `avancado` → falha "só no modo avançado"; senão `AcceptEula()` e entra na `Microsoft.Update.UpdateColl`. Download (`CreateUpdateDownloader`) e instalação (`CreateUpdateInstaller`) da coleção; `GetUpdateResult(i).ResultCode` 2 ou 3 → instalado, senão falha "código N" (`HResult` em hex no erro); `precisaReiniciar` = `RebootRequired`. Progresso: 10 "Procurando", 30 "Baixando N atualizações", 70 "Instalando". Teste: marcador `instalar-<id>.txt` por id aceito; `simular.windows` serve de catálogo; `simular.falharIds` força falha "simulada".
- `atualizarProgramas { ids, confirmado: true }` → `{ atualizados: [id], falhas: [{ id, erro }] }`. Por id: `& $winget upgrade --id $id --exact --silent --accept-package-agreements --accept-source-agreements --disable-interactivity | Out-Null`; `$LASTEXITCODE -eq 0` → atualizado, senão falha "winget terminou com código N". Progresso por id. Teste: marcador `winget-<id>.txt`; `wingetAusente` → toda a chamada `ok:false` "winget não encontrado".

### Task 1: Rust — allowlist e validação

**Files:** `src-tauri/src/acoes.rs`.
